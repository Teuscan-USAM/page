Variables y consultas SQL básicas para PostgreSQL

Usa nombres de tablas y columnas reales de tu módulo. Utiliza consultas parametrizadas y no concatene valores recibidos del usuario.

-- Consultar y filtrar
SELECT id, nombre, estado, created_at
FROM usuarios
ORDER BY created_at DESC;

SELECT id, nombre, correo FROM usuarios
WHERE nombre ILIKE '%ana%' OR correo ILIKE '%@salud.gob.sv%';

-- INNER JOIN
SELECT t.id, t.titulo, u.nombre AS usuario
FROM tickets AS t
INNER JOIN usuarios AS u ON u.id = t.usuario_id
WHERE t.estado = 'abierto' ORDER BY t.id DESC;

-- LEFT JOIN
SELECT u.id, u.nombre, COUNT(t.id) AS total_tickets
FROM usuarios AS u LEFT JOIN tickets AS t ON t.usuario_id = u.id
GROUP BY u.id, u.nombre ORDER BY total_tickets DESC;

-- Insertar, actualizar y borrar
INSERT INTO tickets (titulo, estado, usuario_id)
VALUES ('Revisar acceso al SIS', 'abierto', 10) RETURNING id;

UPDATE tickets SET estado = 'cerrado', updated_at = NOW()
WHERE id = 25 RETURNING id, estado, updated_at;

DELETE FROM tickets WHERE id = 25 RETURNING id;

Consejo: antes de un UPDATE o DELETE, ejecuta el mismo WHERE con SELECT.

Descargar bases de datos en producción por medio de SSH

Utiliza este procedimiento para generar y descargar un respaldo de la base de datos desde el servidor de producción. Reemplaza el nombre de la base y la fecha según corresponda.

Paso 1: Ingresar al servidor por SSH

Desde una terminal de Ubuntu, conéctate al establecimiento:

ssh siap@sis-hzacamil.salud.gob.sv

Paso 2: Generar el respaldo de la base de datos

Después de ingresar por SSH, ejecuta el comando desde la ubicación predeterminada del usuario. No ingreses a la carpeta siaps con cd ni abras PostgreSQL con psql.

pg_dump -U siap -h localhost -p 5432 -Fc -v -O -f sis_hzacamil_20261201.bk siap

El archivo sis_hzacamil_20261201.bk debe incluir el nombre de la base y la fecha de descarga.

Paso 3: Preparar la carpeta local

En tu equipo, abre o crea la carpeta donde guardarás el respaldo de la base de datos (Puede ser windows o Ubuntu).

Paso 4: Descargar el respaldo

Abre una terminal de Ubuntu dentro de la carpeta local y ejecuta scp usando exactamente el mismo nombre del archivo creado:

scp siap@sis-hzacamil.salud.gob.sv:sis_hzacamil_20261201.bk .

Importante: no omitas el punto (.) al final del comando; indica que el archivo se guardará en la carpeta actual.
