Módulo 1

Utilidades generales para dar soporte a los tickets del SIS.

Funcionalidades útiles del SIS

Agregar en la dirección URL: sis-soporte.php/
Ejemplo: https://sis-hzacatecoluca.salud.gob.sv/sis-soporte.php/admin/

Cambiar a otro usuario

Agregar al final de la URL: ?_switch_user=user
Para salir: ?_switch_user=_exit

Variables y consultas SQL básicas para PostgreSQL

Usa nombres de tablas y columnas reales de tu módulo. Utiliza consultas parametrizadas y no concatene valores recibidos del usuario.

-- Consultar y filtrar
SELECT id, nombre, estado, created_at
FROM usuarios
ORDER BY created_at DESC;

SELECT id, nombre, correo FROM usuarios
WHERE nombre ILIKE '%ana%' OR correo ILIKE '%@salud.gob.sv%';

-- INNER JOIN
SELECT t.id, t.titulo, u.nombre AS usuario
FROM tickets AS t
INNER JOIN usuarios AS u ON u.id = t.usuario_id
WHERE t.estado = 'abierto' ORDER BY t.id DESC;

-- LEFT JOIN
SELECT u.id, u.nombre, COUNT(t.id) AS total_tickets
FROM usuarios AS u LEFT JOIN tickets AS t ON t.usuario_id = u.id
GROUP BY u.id, u.nombre ORDER BY total_tickets DESC;

-- Insertar, actualizar y borrar
INSERT INTO tickets (titulo, estado, usuario_id)
VALUES ('Revisar acceso al SIS', 'abierto', 10) RETURNING id;

UPDATE tickets SET estado = 'cerrado', updated_at = NOW()
WHERE id = 25 RETURNING id, estado, updated_at;

DELETE FROM tickets WHERE id = 25 RETURNING id;

Consejo: antes de un UPDATE o DELETE, ejecuta el mismo WHERE con SELECT.
